## Widths are separate

| Field | Vanilla | Expansion | Meaning |
| --- | ---: | ---: | --- |
| Network entity index | 11 bits | 12 bits | `0..2047` → `0..4095` |
| Internal entity-table index | 12 bits | 13 bits | `0..4095` → `0..8191` |
| Internal EHANDLE serial | 15-bit runtime value | 15-bit runtime value | finite lifecycle serial |
| Network serial | 10 bits | 10 bits | encoded in the network protocol |
| PacketEntities count fields | 11-bit sites | 13-bit sites | count/entry capacity, not an index |

The expansion does not turn every integer that resembles an entity index into 13 bits. The patch manifests preserve the individual site decisions and the reports distinguish static inference from runtime observation.

## Storage and ownership

The engine owns the network edict capacity and snapshot/transmit boundaries. The server and client entity lists own their slot arrays and handle extraction. The server also keeps non-network objects in the upper internal range so the old sky-camera and free-list paths do not overlap the new network range.

The highest runtime boundary tested by D65 is network index `4095`, allocated by the normal allocator. It is not a claim that all 4096 network slots were occupied simultaneously.

The server partition is network `0..4095`, reserved slot `4096`, and
non-network pool `4097..8191`. The diagrams' supporting evidence is the
[D61 partition report](../reports/n27d61/findings.md),
[D62 lifecycle acceptance](../reports/n27d62/findings.md), and
[D65 real-load acceptance](../reports/n27d65/findings.md).

## Protocol compatibility

An unmodified client cannot decode an entity index at or above `2048`. A patched client and patched server therefore form a private compatibility island. Steam authentication and ownership remain external requirements; this project does not replace them.

## How the layers fit together

The engine edict array is the network-facing allocation layer. The game module's
`CBaseEntityList` is the ownership and handle layer. Snapshot code translates
the live network edicts into `PacketEntities`; the client frame, bitmap and
baseline stores retain the state needed to decode those deltas. A high-index
entity is therefore valid only when all four layers agree on its width and
storage.

The final server partition is network `0..4095`, reserved slot `4096`, and
non-network `4097..8191`. The internal handle uses 13 index bits and 15 serial
bits; the network serial remains 10 bits. A 4095 observation proves the natural
allocator boundary, not simultaneous occupancy of every network slot.
